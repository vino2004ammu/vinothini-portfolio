# Vinothini I. — Premium Portfolio Website

A modern, high-performance personal portfolio built for **Vinothini I.**, Full Stack Python Developer (Anna University Computer Science graduate, 8.49 CGPA).

## 🚀 Quick Run Locally in VS Code

1. Open **VS Code**.
2. Go to **File → Open Folder** and select this `portfolio/` folder.
3. Install the extension **"Live Server"** by Ritwick Dey (if not already installed).
4. Right-click on `index.html` and select **"Open with Live Server"**.
5. Your browser will immediately launch the portfolio at `http://127.0.0.1:5500`.

## 🌐 Deploying to GitHub Pages (Replace Previous Portfolio)

Your existing GitHub repository is located at:
`https://github.com/vino2004ammu/My_Portfolio-`

To update your live site at `https://vino2004ammu.github.io/My_Portfolio-/`:

```bash
# 1. Clone or open your local repository
git clone https://github.com/vino2004ammu/My_Portfolio-.git
cd My_Portfolio-

# 2. Copy the contents of this folder (index.html, css/, js/) into the repository root.

# 3. Commit and push to GitHub:
git add .
git commit -m "Upgrade to premium modern portfolio architecture"
git push origin main
```

Within 1 to 2 minutes, GitHub Pages will automatically rebuild and deploy your new portfolio!

## 🎨 Easy Customization

- **Change Theme Colors:** Open `css/style.css` and edit the `--primary-color`, `--accent-color`, and `--background-color` variables at the top of the file.
- **Update Personal Details / Contact:** Open `js/main.js` and edit the `PORTFOLIO_CONFIG` object at the top.
